# Teste QA Junior — Verzel Store

Projeto desenvolvido para o teste técnico de QA Junior da Verzel Store.

## Objetivo

Realizar testes funcionais e de API na aplicação Verzel Store, identificando possíveis problemas e automatizando cenários utilizando Playwright.

## Tecnologias e ferramentas

- Testes manuais
- Testes de API
- Postman
- Playwright
- JavaScript
- Git e GitHub

## Cenários de teste

Os cenários de teste foram elaborados com base na documentação fornecida no teste técnico.

- Cenários de testes da aplicação
- Cenários de testes de API
- Execução dos testes
- Relatório de bugs

## Automação

Foram automatizados cenários utilizando Playwright.

Os testes automatizados estão localizados em:

`automacao/tests/`

Para executar os testes:

```bash
npx playwright test
